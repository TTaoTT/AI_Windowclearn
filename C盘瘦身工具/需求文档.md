# C 盘瘦身工具 · 需求文档（PRD）

> 版本：v0.1（草案）
> 日期：2026-08-18
> 状态：待评审

---

## 1. 项目背景与目标

Windows 用户长期面临 **C 盘空间不足** 的痛点：系统更新、应用缓存、用户文件、开发环境产物不断堆积，而多数用户不具备手动定位与迁移的能力。市面上虽有 CCleaner、Dism++、TreeSize、WizTree 等成熟产品，但普遍存在以下割裂：

- **分析工具**（WizTree / TreeSize / WinDirStat）只负责"看见"大文件，不负责"处理"；
- **清理工具**（CCleaner / Dism++ / BleachBit）擅长删除垃圾，但迁移能力弱或不直观；
- **迁移手段**（符号链接 / 用户文件夹重定向）散落在教程和脚本里，缺乏统一、安全、可回滚的产品化入口；
- **防再生**（防止 C 盘再次被不必要文件占满）几乎无人做成一键能力，用户只能反复"救火"。

本项目的目标是打造一款**集"空间分析 → 智能清理 → 安全迁移 → 长效防再生"于一体的 Windows 桌面工具**，让 C 盘持续保持苗条，且整个过程对用户安全、可回滚、可解释。

### 1.1 核心目标（SMART）

| 编号 | 目标 | 度量 |
|------|------|------|
| G1 | 自动识别可清理文件 | 覆盖 ≥ 15 类常见垃圾，扫描准确率（误删率）< 0.1% |
| G2 | 识别可迁移文件且不影响软件运行 | 提供按"风险等级"分类的迁移清单，迁移后软件启动成功率 ≥ 99% |
| G3 | 提供设置与优化防止 C 盘再生 | 内置 ≥ 8 项"防再生"开关，一键开启 |
| G4 | 安全可回滚 | 所有删除/迁移操作默认进入回收站或保留备份，关键操作前自动创建还原点 |
| G5 | 可视化与易用 | 提供树图/列表可视化，普通用户 3 步内完成一次清理或迁移 |

### 1.2 非目标（明确不做）

- 不做磁盘分区调整 / 扩容（Resize Volume）——属于 DiskGenius / AOMEI 领域，风险高且职责不同。
- 不做系统激活、破解、绕过授权相关功能。
- 不收集/上传用户文件与路径信息（本地优先、隐私优先）。
- 不在第一版做企业批量管控 / 域策略下发。

## 2. 目标用户与使用场景

| 用户类型 | 特征 | 核心诉求 |
|----------|------|----------|
| 普通家用用户 | 不懂技术，C 盘红了就慌 | 一键清理、别把电脑搞坏 |
| 开发者 | 装了大量 SDK、包缓存（npm/cargo/.m2）、WSL | 把开发缓存/环境迁到 D 盘，且不破坏工具链 |
| 游戏玩家 | Steam/Epic/游戏缓存占空间大 | 迁移游戏与缓存，启动不受影响 |
| IT 运维 / 进阶用户 | 管理多台机器 | 规则可配置、可脚本化、可批量、有日志 |

**首要场景**：C 盘剩余空间 < 15% 时的"急救 + 长效治理"。

## 3. 核心功能需求

### F1 · 空间分析（可视化定位）

- **F1.1** 扫描指定盘符（默认 C:），以**树图（Treemap）+ 目录树 + 文件类型分布**三种视图呈现空间占用。
- **F1.2** 扫描性能：对 NTFS 卷应优先采用 **MFT 直读**（读取 USN / MFT），在百 GB 级盘上扫描时间 < 10 秒；非 NTFS 或回退场景用递归枚举。
- **F1.3** 自动识别并**过滤系统保护目录**（`$Recycle.Bin`、`System Volume Information`）避免误读。
- **F1.4** 标记"可疑大目录"：结合规则引擎自动给目录打标签（如"浏览器缓存""开发缓存""可迁移用户数据"）。
- **F1.5** 支持"基线快照"：保存当前占用快照，下次扫描对比出**增量增长**，定位"是谁又把 C 盘吃胖了"。
- **F1.6** 结果可导出 CSV / HTML 报告。

### F2 · 自动识别可清理文件

工具需内置**可清理规则库**，按风险分级（安全 / 谨慎 / 高危）呈现，默认仅勾选"安全"级。

| 类别 | 典型路径 / 对象 | 风险 | 处理方式 |
|------|----------------|------|----------|
| 系统临时文件 | `C:\Windows\Temp\*`、`%TEMP%\*` | 安全 | 删除（先回收站） |
| Windows 更新缓存 | `C:\Windows\SoftwareDistribution\Download\*` | 安全 | 停止 wuauserv/bits 后删除 |
| 缩略图缓存 | `ThumbCache_*.db` | 安全 | 删除 |
| 回收站 | `$Recycle.Bin` | 安全 | 清空 |
| 浏览器缓存 | Chrome/Edge/Firefox 缓存目录 | 安全 | 删除（关进程后） |
| 应用缓存 | 微信/QQ/钉钉/Tencent/Teams 缓存 | 安全 | 删除（关进程后） |
| 崩溃转储 | `*.dmp`、`CrashDumps` | 安全 | 删除 |
| 旧日志 | `*.log`、应用 logs 目录（需规则） | 谨慎 | 删除旧于 N 天 |
| **WinSxS 冗余组件** | `C:\Windows\WinSxS` 中被取代版本 | 谨慎 | 经 `DISM /Online /Cleanup-Image /StartComponentCleanup` 安全回收 |
| 休眠文件 | `hiberfil.sys` | 谨慎 | `powercfg -h off`（需确认，影响休眠） |
| 系统还原点 / 旧备份 | `System Volume Information`、Windows.old | 谨慎 | 经系统 API / 磁盘清理删除 |
| 重复文件 | 用户指定目录内哈希相同的副本 | 谨慎 | 删重（保留一份） |

> **不可清理红线**（工具必须内置黑名单，永不主动删除）：
> `C:\Windows\Installer`（MSI 数据库，删了无法修复/卸载）、`C:\Windows\System32` 主体、`C:\Program Files\*` 主体程序、`AppData\Local\Packages`（UWP 沙箱整体）、驱动与 DriverStore、注册表关键项。

### F3 · 识别可迁移文件（不影响软件运行）

核心思路：**物理文件搬到非系统盘，用目录联接（Junction）或符号链接（Symlink）在 C 盘原路径留"替身"**，系统与软件仍走原路径，无感重定向。

按风险等级给出迁移清单：

| 等级 | 对象 | 技术路径 | 说明 |
|------|------|----------|------|
| L1 低风险 | 用户文档/图片/下载/桌面/视频/音乐 | **Shell 文件夹重定向**（改注册表 `User Shell Folders`） | 微软官方支持，零风险 |
| L2 中风险 | `AppData\Roaming` 中特定软件配置/插件、`AppData\Local` 中大型缓存（浏览器、Tencent、JetBrains、Teams） | 关进程 → `robocopy /COPYALL` 复制 → 删源 → `mklink /J` 建联接 | 可能影响个别软件更新，需验证 |
| L3 高风险 | 装在 C 盘的第三方大型软件/游戏（无自带迁移功能者） | `mklink /J` 物理映射 | 依赖文件系统稳定性；杀软/驱动/VPN/反作弊类禁用 |
| L1(系统) | UWP/商店应用、WSL 发行版 | 系统"设置→应用→移动" / `wsl --export`+重定位 | 走官方通道，不手动 junction |

- **F3.1** 迁移前**自动结束占用进程**（按规则匹配 exe 名，`taskkill`）。
- **F3.2** 复制保留 **ACL/时间戳/所有权**（`robocopy /COPYALL /E`）。
- **F3.3** 建链后**启动自检**：尝试启动关联 exe 或校验关键文件可读写。
- **F3.4** 迁移计划可**预览**（显示"源→目标→链接类型→风险"），用户确认后执行。
- **F3.5** 提供**回滚**：删除链接 + 把数据搬回原路径（或保留 D 盘副本，仅删链接即可还原）。
- **F3.6** 记录"已 junction 清单"，供后续排查与统一回滚。

### F4 · 设置与优化（防止 C 盘再生）

把"长效健康"做成一键开关，而非依赖用户记忆：

| 开关 | 作用 | 实现机制 |
|------|------|----------|
| 存储感知（Storage Sense） | 自动定期清临时文件/回收站 | 配置 `StorageSense` 注册表/设置 |
| 用户文件夹重定向 | 文档/下载/桌面默认落 D 盘 | 改 `User Shell Folders` |
| 默认保存位置 | 新文件默认存 D 盘 | `Settings → Storage → More storage settings` |
| NTFS 压缩策略 | 对可压缩目录（源码/日志/配置）定点压缩 | `compact.exe` / 高级属性 |
| OneDrive 文件随选 | 云端文件不常驻本地 | Files On-Demand |
| UWP 默认安装盘 | 新装商店应用落非系统盘 | `Settings → Storage → New apps will save to` |
| 开发环境路径集中管理 | 引导 npm/cargo/Maven/Gradle/pip 缓存改到 D 盘 | 改环境变量 / 配置文件 |
| 浏览器下载路径 | Chrome/Edge 默认下载目录改 D 盘 | 改浏览器策略/配置 |
| 休眠文件关闭 | 释放与内存等大的空间 | `powercfg -h off`（可选） |
| 页面文件托管 | pagefile 迁到非系统盘（可选） | 系统高级设置 |

- **F4.1** 每项开关显示"预计收益 / 风险说明 / 是否需重启"。
- **F4.2** 开关状态可保存为"配置方案"，一键应用或导出。

### F5 · 安全与回滚机制

- **F5.1** 删除默认走**回收站**（经 `SHFileOperation`/`IFileOperation`），而非硬删除；仅"高危强删"类（如系统清理 API）例外并明确提示。
- **F5.2** 关键批量操作（迁移/大批量清理）前**自动创建系统还原点**（或 VSS 快照）。
- **F5.3** 内置**白名单（永不删/迁）/ 黑名单（强制忽略）**可编辑。
- **F5.4** 所有操作写入**事务日志**（时间、操作、路径、结果、回滚方式），可审计、可重放。
- **F5.5** 删除/迁移前**二次确认**，展示影响范围与可回收性。
- **F5.6** 需**管理员权限**运行（UAC 清单），无权限时降级提示并仅开放安全功能。
- **F5.7** 对"正在使用/锁定"的文件，给出占用进程提示与跳过选项，不强行破坏。

### F6 · 报告、调度与自动化

- **F6.1** 支持**计划任务**：每周/每月自动扫描并生成趋势报告（集成 Windows 任务计划程序）。
- **F6.2** 提供"一键优化"向导：普通用户勾选建议项后一键执行（清理 + 防再生开启）。
- **F6.3** 报告含：可回收空间、可迁移空间、已生效防再生项、历史趋势曲线。

## 4. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | NTFS 盘扫描 < 10s（MFT 直读）；清理/迁移带宽受磁盘 IO 限制，提供进度与预估时间 |
| 兼容性 | 支持 Windows 10 / 11（x64）；ARM64 可作后续目标 |
| 权限 | 默认需管理员；非管理员下可运行"安全子集" |
| 隐私 | 全程本地执行，不上传任何文件/路径/内容 |
| 可靠性 | 任一操作失败不影响其余；失败可定位、可回滚 |
| 可维护性 | 规则库与代码解耦（规则以 XML/JSON 描述），便于社区/用户扩充 |
| 可访问性 | 关键操作有清晰文案与风险提示；支持中文界面 |

## 5. 与市面成熟产品对比 & 差异化

| 能力 | CCleaner | Dism++ | WizTree | TreeSize | 本工具目标 |
|------|----------|--------|---------|----------|-----------|
| 空间可视化 | 弱 | 无 | 强（MFT） | 强 | 强（MFT + 标签） |
| 系统深度清理 | 中 | 强（CBS） | 无 | 无 | 强（规则库 + CBS/CompactOS） |
| 安全迁移 | 无 | 无 | 无 | 无 | **核心差异点** |
| 防再生设置 | 弱 | 部分 | 无 | 无 | **核心差异点** |
| 可回滚 | 部分 | 强 | 无 | 无 | 强（还原点+日志+回收站） |
| 规则可扩展 | 否 | 是（Data.xml） | 否 | 部分 | 是 |
| 免费本地 | 含广告 | 是 | 个人免费 | 免费版 | 是（开源优先） |

**差异化定位**：不做"又一个清理器"，而是做 **C 盘空间的全生命周期治理台**——看见 → 清理 → 迁移 → 防止再生，且每一步安全可回滚。

## 6. 验收标准（首版 MVP）

1. 扫描 C 盘并在 10s 内展示 Top 大目录树图；
2. 一键清理"安全级"垃圾，实测释放空间与系统磁盘清理（cleanmgr）结果一致、无系统异常；
3. 提供 ≥ 10 条"可迁移清单"，对其中 L1/L2 项迁移后对应软件可正常启动；
4. "防再生"面板 ≥ 8 项开关可一键开启并真实生效；
5. 任意删除/迁移操作均可在日志中追溯，且提供回滚入口；
6. 全程本地运行，无网络请求涉及用户数据。

## 7. 风险与边界

- **误删风险**：靠规则分级 + 回收站 + 黑名单 + 二次确认多层防御。
- **迁移导致软件异常**：靠风险分级、进程关闭、启动自检、回滚清单控制。
- **权限不足**：UAC 提权，无权限降级运行安全子集。
- **系统版本差异**：规则库按 OS 版本适配，未知版本走保守策略。
- **不可逆操作**：休眠关闭、还原点删除、CompactOS 等标为"谨慎/需确认"，默认不勾选。
